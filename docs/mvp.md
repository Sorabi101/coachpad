# MVP (Minimum Viable Product)

## Goal

CoachPad enables tennis coaches to manage players, training sessions and player development in one centralized platform.

The MVP focuses on reducing administrative work while improving long-term player documentation.

---

# Included Features

## 1. Authentication

- Register
- Login
- Logout

---

## 2. Player Management

The coach can

- create players
- edit players
- delete players
- view player profiles

Each player contains

- personal information
- contact information
- playing level
- notes
- goals

---

## 3. Training Session Management

The coach can

- create a training session
- select date
- select start and end time
- enter the location
- assign one or more players
- add a short description

---

## 4. Training Documentation

After each session the coach can

- write training notes
- document strengths
- document weaknesses
- assign homework
- rate the player's performance

---

## 5. Player Goals

The coach can

- create goals
- update goals
- mark goals as completed
- review previous goals

---

## 6. Exercise Library

The coach can

- create custom exercises
- organize exercises by category
- reuse exercises in future training sessions

---

# Not Included

The following features are intentionally excluded from the MVP.

- Court booking
- Payment management
- Chat
- Push notifications
- AI recommendations
- Video analysis
- Statistics dashboard
- Multi-sport support
- Parent accounts
- Player accounts

---

# Success Criteria

The MVP is considered successful if a tennis coach can

- manage players
- plan training sessions
- assign players to sessions
- document player development
- reuse exercises

without relying on external tools such as Notion, paper notes or spreadsheets.
