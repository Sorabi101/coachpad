# Domain Model

## Coach

Represents a tennis coach using CoachPad.

Responsibilities:

- manages players
- creates training sessions
- writes training notes
- creates exercises
- defines player goals

---

## Player

Represents a tennis player.

Contains:

- personal information
- contact information
- playing level
- goals
- training history

---

## Training Session

Represents a single training session.

Contains:

- date
- time
- location
- participants
- exercises
- notes

---

## Exercise

Represents a reusable tennis exercise.

Contains:

- title
- description
- category
- duration

---

## Training Note

Represents feedback after a training session.

Contains:

- strengths
- weaknesses
- homework
- general notes

---

## Goal

Represents an objective for a player.

Examples:

- Improve serve consistency
- Learn kick serve
- Improve footwork
