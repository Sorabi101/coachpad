# Open Questions

## Purpose

This document collects open product and technical questions that still need to be answered before implementation.

The goal is not to answer every question immediately, but to identify uncertainties early and track important product decisions throughout the project.

---

# Players

- Can a player belong to multiple coaches?
- Does a player need an account in the MVP?
- Should parents be stored as emergency or primary contacts for junior players?
- Should players be archived instead of permanently deleted?
- What information should every player profile contain?

---

# Training Sessions

- Can a training session include multiple players?
- Should recurring training sessions be supported?
- Can a training session be cancelled or rescheduled?
- Can completed training sessions be edited afterwards?
- Should training sessions support both individual and group training?

---

# Training Notes

- Are training notes only visible to the coach?
- Should notes belong to a training session or directly to a player?
- Can one note refer to multiple players?
- Should notes support attachments such as images or videos?

---

# Goals

- Can a player have multiple active goals?
- Should goals have deadlines?
- Should completed goals remain visible in the player's history?

---

# Exercise Library

- Can exercises be assigned directly to a training session?
- Can coaches create their own custom exercises?
- Should exercises be categorized (e.g., Forehand, Backhand, Footwork, Fitness)?
- Should exercises be reusable across multiple training sessions?

---

# General

- Is CoachPad initially designed only for individual tennis coaches?
- Should the MVP be optimized for mobile devices first?
- Which information is mandatory and which is optional?
- Should CoachPad support only tennis in the first version?
- Which features provide the highest value for the MVP?

---

# Future Considerations

These questions are intentionally postponed and are **not** part of the MVP.

- Should players receive their own accounts?
- Should parents have separate accounts?
- Should coaches be able to communicate through an integrated chat?
- Should AI generate training plans automatically?
- Should CoachPad support additional sports in the future?
