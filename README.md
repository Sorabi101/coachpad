# CoachPad

## Overview

CoachPad is a platform for tennis coaches that helps reduce administrative work and document player development over time.

## Motivation

Many tennis coaches organize their work using messaging apps, paper notes, calendars and spreadsheets. CoachPad aims to centralize player management, training planning and training documentation in one place.

## MVP Features

- Manage players
- Create reusable training drafts
- Create training sessions
- Assign exercises
- Document training notes
- Track player development over time
